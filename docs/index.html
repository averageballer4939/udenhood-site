Getting started

How Udenhood works.

A coin should come from a repo that signed it. Four lights show if the project behind it exists, runs and ships.

Open Check, paste a public GitHub repo and press Pop the hood: your browser asks GitHub and four lights answer.

What works today

  • Check a repo. Paste any public repo and read its four lights. No account, no key. How a check runs.
  • Sign your repo. Add one small file that names your wallet. It lights Owner halfway. How to sign.

Not live yet. Launching a coin, the fee vault and UDEN. They are listed, without dates, on In build.
